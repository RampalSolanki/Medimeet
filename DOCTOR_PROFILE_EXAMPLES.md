## Form Instructions (Step-by-Step with Example)

### Step 1: After Sign-Up

You'll see the onboarding page with these fields:

```
┌─────────────────────────────────────┐
│  What's your role?                  │
│  ○ Patient                          │
│  ● Doctor                           │  ← Select this
└─────────────────────────────────────┘
```

### Step 2: Doctor-Specific Fields Appear

```
┌─────────────────────────────────────┐
│  Specialty:  [Cardiologist____]     │  ← Type "Cardiologist" or pick from dropdown
│                                     │
│  Years of Experience: [10]          │  ← Enter a number (5-40)
│                                     │
│  Link to Credential Document:       │
│  [https://via.placeholder...]       │  ← Paste one of the test URLs
│                                     │
│  Service Description:               │
│  [I specialize in cardiac care...] │  ← Write 2-3 sentences about your expertise
│                                     │
│  [Submit Button]                    │
└─────────────────────────────────────┘
```

### Step 3: Verification Screen

After clicking Submit, you'll see:

```
┌──────────────────────────────────┐
│  ✓ Profile Submitted!            │
│                                  │
│  Status: Waiting for Verification│
│  Your profile is under review.   │
│  An admin will verify your       │
│  credentials shortly.            │
│                                  │
│  [Go to Profile]                 │
└──────────────────────────────────┘
```

## After Form Submission

Once you submit:

1. You'll see **"Waiting for Verification"** status
2. Go to Prisma Studio to promote yourself to ADMIN
3. Then access `/admin` dashboard
4. Approve your own pending doctor application
5. Access `/doctor` dashboard to see your doctor workspace

---

## Tips for Realistic Testing

- Use real specialty names (avoid made-up ones)
- Experience should be 1-50 years (realistic range)
- Write genuine-sounding descriptions (2-3 sentences)
- Use one of the provided test URLs for credentials
- After verification, set your availability slots to complete the setup

## Common Fields Explained

| Field                   | What to Write                    | Example                                              |
| ----------------------- | -------------------------------- | ---------------------------------------------------- |
| **Specialty**           | Medical field/expertise          | "Cardiologist", "Dentist", "Pediatrician"            |
| **Years of Experience** | Number of years practicing       | "10", "8", "15"                                      |
| **Credential URL**      | Link to your credential document | Use one of the test URLs provided                    |
| **Service Description** | Brief overview of your services  | "I specialize in... I have X years of experience..." |
